# Fortune’s Weave Gift Almanac

Search gift preferences for the 75 characters in *Fire Emblem: Fortune’s Weave*. Type a name or browse the full roster.

## Run locally

Requires [Bun](https://bun.sh/).

```sh
bun install
bun run dev
```

To build the site, run `bun run build`.

## Gift data

Named gifts come from Game8’s “Preferred Gift” list and are checked against the [Fortunes-Weave-Helper reference database](https://github.com/Rico0319/Fortunes-Weave-Helper). [GameSpot](https://www.gamespot.com/articles/fire-emblem-fortunes-weave-gifts-guide/) and [Nintendo Insider](https://www.nintendo-insider.com/fire-emblem-fortunes-weave-characters-gifts-likes-and-interests/) provide additional context, but do not confirm each item’s reaction tier.

For that reason, listed items appear as “Preferred.” “Loved” gifts will be added only when at least two independent sources confirm the top-tier reaction. Characters without named gifts remain searchable.

## Recruitment notes

Automatic recruitment notes appear under a character’s gift list only when a guide confirms an automatic join. They identify the Flame Lord path and include known later-part conditions. Other characters generally require manual recruitment or are not recruitable on that path. Recruitment details are based on [RPG Site’s route-by-route recruitment guide](https://www.rpgsite.net/guide/21391-fire-emblem-fortunes-weave-recruitment-guide-all-characters-in-game-how-to-recruit-them).
